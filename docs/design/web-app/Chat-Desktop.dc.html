What's the difference between a stack and a queue?
10:42 · Edit
Tutor · 10:42 · 3.1 KB · 2 sources

A stack is last-in, first-out: the last item you push is the first one you pop. A queue is first-in, first-out: items leave in the order they arrived.

Lecture 6: Stacks & Queues Page 3 of 18
6.1 The stack ADT

A stack is an ordered collection in which insertion and removal happen at the same end, called the top.

The element added last is the first to be removed. For this reason a stack is described as last-in, first-out (LIFO).

The two core operations are push, which places an element on the top, and pop, which removes the element on the top and returns it.

A third operation, peek, returns the top element without removing it.

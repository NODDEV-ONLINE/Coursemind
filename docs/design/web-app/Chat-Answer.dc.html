What's the difference between a stack and a queue?
10:42
Tutor · 10:42 · 3.1 KB

A stack is last-in, first-out: the last item you push is the first one you pop. A queue is first-in, first-out: items leave in the order they arrived.

Your slides use a pile of plates for a stack and a bank counter line for a queue.
